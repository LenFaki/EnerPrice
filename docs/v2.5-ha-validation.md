# EnerPrice v2.5 — Home Assistant release validation

Use this checklist on a real Home Assistant installation after CI is green. It complements automated tests; it does not replace them.

## 1. Upgrade and lifecycle

- Update EnerPrice from the phase/release build and restart Home Assistant once.
- Confirm existing price entities and existing automations still load.
- With Smart Setup disabled, confirm no Smart Energy Advisor entity is created for that config entry.
- Enable Smart Setup in the EnerPrice options. Saving the options must reload the entry and create **Smart Energy Advisor** without a full Home Assistant restart.
- Disable Smart Setup again and confirm the advisor disappears after the entry reloads.

## 2. Configure live inputs

Enable Smart Setup again and select the actual installation entities:

- grid/P1 power: W, positive = import, negative = export;
- solar production: W;
- gas price: EUR/m³;
- one flexible load and its electrical power.

Change each selected grid/P1, solar and gas entity once. The Smart Energy Advisor must refresh without waiting for the next market-price update. Then change one selected entity ID in EnerPrice options and confirm the integration reloads and follows the new entity.

## 3. Advice sanity checks

Observe or simulate these situations without letting EnerPrice directly control equipment:

- negative grid power/export large enough for the configured load -> surplus context;
- positive grid import -> no false solar-surplus state;
- cheaper future interval -> `wait` when the configured thresholds make that appropriate;
- electricity useful-heat cost below gas -> electric/cheap-grid advice;
- gas useful-heat cost below electricity -> gas advice;
- unavailable gas/solar/grid input -> unknown/missing context, never an invented zero measurement.

Check that recommendation text follows the configured advice language.

## 4. Hourly and quarter-hour prices

Generate advice/dashboard once with hourly data and once with quarter-hour data when available. Confirm:

- current all-in price matches the active interval;
- next-better time aligns to a real source interval;
- the graph and planning text do not assume one-hour steps.

## 5. Dashboard generator

Run `nl_day_ahead_prices.generate_dashboard_yaml` with `dashboard_type: energy_advisor`.

Confirm the generated YAML:

- references the actual Entity Registry IDs;
- prominently shows Smart Energy Advisor;
- includes only configured P1/solar/gas sections;
- shows current price and next-better timing;
- renders on desktop and a narrow mobile screen;
- documents/requires ApexCharts only where a generated graph uses it.

## 6. Pass criteria

V2.5 phase 6 passes when CI is green and all applicable checks above work without errors, stale listeners, false zero measurements or automatic device switching. Record any installation-specific entity IDs only in local test notes; do not commit personal Home Assistant configuration to the repository.
