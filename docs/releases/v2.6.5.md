# EnerPrice 2.6.5 — Export price improvements and Daily Advisor diagnostics / Verbeterde terugleverprijzen en diagnostiek

## English

### Added
- Add a **Current Sell Price** sensor to show the current export compensation.
- Add an optional export-market VAT setting for supported supplier calculations.

### Improved
- Reuse cached sell-price entries for the new sensor and related attributes, avoiding unnecessary recomputation on repeated Home Assistant state reads.
- Apply supplier export tariffs consistently across date-based tariff changes, including the boundary between August and September.
- Add finer-grained Daily Energy Advisor performance logging to distinguish snapshot collection from export-price calculation when updates are slow.

### Update and verify
1. Update EnerPrice to **2.6.5** through HACS and restart Home Assistant.
2. Check the Current Sell Price sensor and relevant export-price settings, if configured.
3. Inspect **Settings → System → Logs** if the Daily Energy Advice sensor still triggers slow-update warnings. The new diagnostic breakdown helps locate the delay.

These changes improve observability and avoid repeated calculations; they do not guarantee that all slow-update warnings disappear.

## Nederlands

### Toegevoegd
- Een sensor **Huidige terugleverprijs** die de actuele vergoeding voor teruglevering toont.
- Een optionele instelling voor btw op de teruglevermarkt bij ondersteunde leveranciersberekeningen.

### Verbeterd
- De nieuwe sensor en bijbehorende attributen hergebruiken terugleverprijzen uit de cache, zodat Home Assistant niet telkens de volledige reeks opnieuw hoeft te berekenen.
- Leverancierstarieven voor teruglevering worden consequent toegepast bij datumgebonden tariefwijzigingen, waaronder de overgang van augustus naar september.
- Gedetailleerdere prestatiemetingen voor **Dagelijks energieadvies** maken onderscheid tussen het verzamelen van de momentopname en het berekenen van terugleverprijzen.

### Bijwerken en controleren
1. Werk EnerPrice via HACS bij naar **2.6.5** en herstart Home Assistant.
2. Controleer de sensor Huidige terugleverprijs en de relevante terugleverinstellingen, indien ingesteld.
3. Bekijk **Instellingen → Systeem → Logboeken** als Dagelijks energieadvies nog waarschuwingen over trage updates geeft. De nieuwe diagnostiek helpt de oorzaak lokaliseren.

De wijzigingen maken de prestaties inzichtelijker en voorkomen overbodige berekeningen, maar garanderen niet dat alle waarschuwingen verdwijnen.
