# EnerPrice 2.6.6 — Robust handling of empty provider JSON / Betere afhandeling van lege provider-JSON

## English

### Fixed
- Handle a price provider returning a literal JSON `null` response without passing it to the price parsers.
- Retry this empty response using the existing retry policy and raise a clear provider error if all attempts fail.
- Add regression tests for retry success and retry exhaustion (contributed by **hvandonge**, PR #66).

### Update and verify
1. Update EnerPrice to **2.6.6** through HACS and restart Home Assistant.
2. Check that price sensors continue updating normally. Temporary empty provider responses are now retried rather than causing a parser AttributeError.

---

## Nederlands

### Opgelost
- Een prijsprovider die letterlijk JSON `null` teruggeeft, veroorzaakt niet langer een AttributeError in de prijsverwerking.
- Een dergelijke lege respons wordt opnieuw geprobeerd volgens het bestaande retrybeleid. Als alle pogingen mislukken, wordt een duidelijke providerfout gemeld.
- Regressietests toegevoegd voor zowel een geslaagde herpoging als het bereiken van het maximumaantal pogingen (bijdrage van **hvandonge**, PR #66).

### Bijwerken en controleren
1. Werk EnerPrice via HACS bij naar **2.6.6** en herstart Home Assistant.
2. Controleer of de prijssensoren normaal blijven bijwerken. Tijdelijk lege providerresponses worden nu opnieuw geprobeerd in plaats van een parserfout te veroorzaken.

---

**Compatibility / Compatibiliteit:** Existing configuration and entity IDs remain unchanged. / Bestaande instellingen en entiteits-ID's blijven ongewijzigd.
